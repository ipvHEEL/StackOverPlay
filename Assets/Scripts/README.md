# База 2D-заводостроилки

Нажми **Play** в любой сцене — `GameBootstrap` сам создаст мир, игрока, камеру и HUD.

## Управление
- WASD — ходить, колесо — зум
- ПКМ (зажать) на руде — копать руками
- 1–4 — выбрать здание, R — поворот, Q — отмена
- ЛКМ — построить (можно зажать и вести), ПКМ — разобрать, F — забрать содержимое

## Структура
| Файл | Что делает |
|---|---|
| `Core/GameBootstrap.cs` | Точка входа, сборка сцены, стартовые ресурсы |
| `Core/Items.cs` | Список предметов, их имена/цвета, рецепты печи |
| `Core/Inventory.cs` | Инвентарь (игрок, сундук) |
| `Core/SpriteFactory.cs` | Генерация квадратных спрайтов + порядок слоёв |
| `World/WorldGrid.cs` | Генерация карты, тайлы, руда, сетка зданий |
| `Buildings/Building.cs` | Базовый класс здания (`TryInsert`, `PushForward`, `TakeContents`) |
| `Buildings/BuildingDatabase.cs` | Описания зданий: цена, цвет, хоткей, правила постройки |
| `Buildings/*.cs` | Конвейер, бур, печь, сундук |
| `Player/*.cs` | Движение и копание, строительство, камера |
| `UI/HUD.cs` | Временный интерфейс на OnGUI |

## Как добавить здание
1. Добавь значение в `BuildingType`.
2. Создай класс `MyBuilding : Building`, переопредели `TryInsert` / `Update` / `GetInfo`.
3. Добавь `new BuildingDef { ... Component = typeof(MyBuilding) }` в `BuildingDatabase.All`.
